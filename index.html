实时 API 驱动

利用无监督机器学习自动识别学术前沿，揭示深度学习、数字孪生在 SHM 领域的融合趋势。

项目背景与技术架构 (Methodology)

  • 业务场景：为工程院系提供自动化的新兴交叉学科预警与动态文献导航。
  • 底层技术栈：Python / arXiv API / scikit-learn / Plotly / Github Actions (CI/CD)
  • 算法逻辑：通过 API 拉取近5年文献，采用 TF-IDF 进行文本向量化，并部署 NMF 非负矩阵分解 抽取标题和摘要共现核心词汇，结合 t-SNE 构建反映热门研究方向的高维语义空间映射图。
